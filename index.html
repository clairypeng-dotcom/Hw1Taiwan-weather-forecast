💡 如何取得中央氣象署 API 授權碼？
  1. 前往 氣象資料開放平臺 免費註冊帳號。
  2. 登入後點擊右上角「會員資訊」➔「取得授權碼」。
  3. 將授權碼（格式如 CWA-XXXXXXXX-...）貼入下方輸入框即可連線即時氣象局測站！
